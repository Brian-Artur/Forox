# IN
El operador `IN` se usa para **comparar un valor con una lista de valores**. Si el valor que estás evaluando **coincide con alguno de los elementos de la lista**, la condición es verdadera.
![[ED2025-06-05_08.54.37|600|center]]
Lo que hay dentro del `IN` sería como un Array de elementos. Son todos los valores que pueden coincidir. Como si se tratase de una serie de `OR` concatenados. 

Es muy práctico para realizar una subconsulta y que te devuelva una lista de resultados dinámica.  

![[ED2025-06-05_09.32.59|250]]
# EXISTS
El operador `EXISTS` en SQL se usa para **verificar si una subconsulta devuelve al menos una fila**.  
No importa qué columnas devuelva la subconsulta ni qué valores tenga, **solo importa si hay resultados**.

¿La subconsulta devuelve algo?  
✅ Sí → la condición es verdadera  
❌ No → la condición es falsa

El ultimo id que tenga cualquier tabla.

# Ejercicio
Crear un proyecto backend con typescript. Sin frontend.
- Conectarse con la base de datos
- Crear base de datos si no existe.
- Usar base de datos
- Crear tabla
- Anadir datos
- Borrar la tabla
- Borrar base de datos
- Programas independientes. Uno por sentencia.
- desde terminal llamar a uno u otro programa

## 1. Inicializar el proyecto
```bash
mkdir mariadb-project
cd mariadb-project
npm init -y
npm install typescript ts-node @types/node --save-dev
npx tsc --init
```
## 2. Instalar dependencias
```bash
npm install mysql2 dotenv
```
## 3. Archivo `.env`
```bash
DB_HOST=localhost
DB_USER=root
DB_PASSWORD=tu_password
DB_NAME=demo_db
```
