# Instalar WP en MV
## 1. Actualizar el sistema

```bash
sudo apt update && sudo apt upgrade -y
```
- **`update`**: Actualiza la lista de paquetes disponibles (pero no los instala).  
- **`upgrade`**: Instala las nuevas versiones de los paquetes ya instalados.      
- **`-y`**: Confirma automáticamente ("yes") para evitar preguntas durante la instalación.  
## 2. Preparar el entorno para WordPress
### **2.1 Instalar dependencias adicionales**

```bash
sudo apt install -y php-curl php-gd php-mbstring php-xml php-xmlrpc php-soap php-intl php-zip
```
- WordPress necesita estos módulos de PHP para funciones avanzadas (subida de archivos, imágenes, etc.).  
### **2.2 Ajustar PHP (para mejor rendimiento)**

Edita el archivo de configuración de PHP:
```bash
sudo nano /etc/php/8.2/apache2/php.ini
```
Busca y modifica estos valores (usa `Ctrl+W` para buscar en nano):
```ini
memory_limit = 256M
upload_max_filesize = 64M
post_max_size = 128M
max_execution_time = 300
```
- **¿Por qué?**: WordPress necesita más memoria para plugins/themes pesados y para subir archivos grandes.
Reinicia Apache para aplicar cambios:
```bash
sudo systemctl restart apache2
```

# Indices
## ¿Qué son los índices en bases de datos?

Los índices son estructuras de datos especiales que mejoran significativamente la velocidad de las operaciones de búsqueda y recuperación en una base de datos. Funcionan de manera similar al índice de un libro, permitiendo al motor de la base de datos encontrar datos específicos sin tener que escanear toda la tabla.
## Tipos principales de índices

### 1. Índices B-Tree (Árbol-B)
- **Estructura**: Árbol balanceado que permite búsquedas, inserciones y eliminaciones en tiempo logarítmico
- **Uso ideal**: Consultas con operadores `=`, `>`, `<`, `BETWEEN`, `LIKE 'patrón%'`
- **Ejemplo**: `CREATE INDEX idx_lastname ON personas(last_name)`

### 2. Índices Hash

- **Estructura**: Tabla hash para búsquedas exactas
    
- **Uso ideal**: Igualdades exactas (`=`), no sirve para rangos
    
- **Ejemplo**: `CREATE INDEX idx_hash ON usuarios USING HASH(email)`
    

### 3. Índices Compuestos (Composite)

- **Estructura**: Índice sobre múltiples columnas
    
- **Uso ideal**: Consultas que filtran por varias columnas
    
- **Ejemplo**: `CREATE INDEX idx_name_country ON clientes(apellido, pais)`

## 🧠 ¿Qué es `ST_GeomFromText()`?

`ST_GeomFromText()` es una función del **sistema de tipos espaciales de MariaDB/MySQL** (y de muchos otros sistemas de bases de datos que implementan el estándar OGC).

Su objetivo es:

> **Construir un objeto geométrico** (como un punto, línea o polígono) **a partir de una cadena de texto** que describe una figura en un formato estándar llamado **WKT**.

## 📏 ¿Qué es WKT?

**WKT** significa **Well-Known Text**. Es un formato de texto plano definido por el estándar [OGC (Open Geospatial Consortium)](https://www.ogc.org/) para describir objetos geométricos como:

- `POINT`
    
- `LINESTRING`
    
- `POLYGON`
    
- `MULTIPOINT`
    
- `GEOMETRYCOLLECTION`
    
- etc.
    

### Ejemplos de WKT válidos:

|Geometría|WKT|
|---|---|
|Punto|`POINT(-8.1114 42.6607)`|
|Línea|`LINESTRING(1 1, 2 2, 3 3)`|
|Polígono|`POLYGON((0 0, 1 0, 1 1, 0 1, 0 0))`|

> ⚠️ Nota: el orden de los valores en `POINT(x y)` es: **x = longitud, y = latitud**.

# Instalar Obasidian en Linux debian.

```bash
sudo apt install curl wget -y
```

## Descargar obsidian
```bash
wget -q -O - [https://api.github.com/repos/obsidianmd/obsidian-releases/releases/latest](https://api.github.com/repos/obsidianmd/obsidian-releases/releases/latest) \
| grep 'deb"$' \
| awk -F'"' '{print $4}' \
| wget -i -
```
Para que no sea con el AptImage.
