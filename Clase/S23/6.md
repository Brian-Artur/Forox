# Instalar WP en MV
## 1. Actualizar el sistema

```bash
sudo apt update && sudo apt upgrade -y
```
- **`update`**: Actualiza la lista de paquetes disponibles (pero no los instala).  
- **`upgrade`**: Instala las nuevas versiones de los paquetes ya instalados.      
- **`-y`**: Confirma automáticamente ("yes") para evitar preguntas durante la instalación.  
## 2. Preparar el entorno para WordPress
### **2.1 Instalar dependencias adicionales**

```bash
sudo apt install -y php-curl php-gd php-mbstring php-xml php-xmlrpc php-soap php-intl php-zip
```
- WordPress necesita estos módulos de PHP para funciones avanzadas (subida de archivos, imágenes, etc.).  
### **2.2 Ajustar PHP (para mejor rendimiento)**

Edita el archivo de configuración de PHP:
```bash
sudo nano /etc/php/8.2/apache2/php.ini
```
Busca y modifica estos valores (usa `Ctrl+W` para buscar en nano):
```ini
memory_limit = 256M
upload_max_filesize = 64M
post_max_size = 128M
max_execution_time = 300
```
- **¿Por qué?**: WordPress necesita más memoria para plugins/themes pesados y para subir archivos grandes.
Reinicia Apache para aplicar cambios:
```bash
sudo systemctl restart apache2
```
