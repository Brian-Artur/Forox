# Replicación de bases de datos

![ED2025-06-02_12.34.15](ED2025-06-02_12.34.15.md)

Para el caso anterior que teníamos que realizar una partición de tablas. Lo ideal sería crear una replica de esta, mediante la replicación Maestro-Esclavo. Una vez que ya se haya generado esa replica, desvinculamos esa replica esclava. De esta forma podremos hacer cambios en la maestra sin que afecte a la esclava. Así, si la liamos en la original, tendremos una "copia de seguridad".

Hacer tabla relacionada que tenga su pripio id, que tenga un fk 

```sql
CREATE TABLE `personas_relacionada` (
    `personas_relacion_id` INT(11) NOT NULL AUTO_INCREMENT,
    `persona_id` INT(11) NOT NULL COMMENT 'ID de la persona relacionada',
    `numero_telefono` VARCHAR(20) NOT NULL COMMENT 'Número de teléfono',
    PRIMARY KEY (`personas_relacion_id`) USING BTREE,
    INDEX `fk_persona_id` (`persona_id`) USING BTREE,
    CONSTRAINT `fk_personas_relacionada` 
        FOREIGN KEY (`persona_id`) 
        REFERENCES `personas` (`persona_id`)
        ON DELETE CASCADE
        ON UPDATE CASCADE
)
COMMENT='Tabla para relacionar personas con números de teléfono'
COLLATE='utf8mb4_spanish2_ci'
ENGINE=InnoDB;
```
