# CORS
## Las siglas **CORS**

- **Cross-Origin** → "Origen cruzado", es decir, cuando una página web hace una solicitud a un dominio diferente del que la sirvió originalmente.
- **Resource** → "Recurso", como un archivo JSON, una imagen, un endpoint de API, etc.
- **Sharing** → "Compartición", se refiere a permitir (o no) el acceso a esos recursos desde otros orígenes.

**CORS** es, por tanto, una **política de seguridad que define cómo los navegadores deben permitir (o denegar) el acceso a recursos web entre diferentes orígenes**.

# Axios
**Axios** es una librería de cliente HTTP basada en _promesas_ que se usa para hacer peticiones desde el navegador o desde Node.js (como `fetch`, pero con más funcionalidades de fábrica).
Se instala con:
```bash
npm install axios
```

Y se usa así:
```js
import axios from 'axios';

axios.get('https://api.ejemplo.com/datos')
  .then(res => console.log(res.data))
  .catch(err => console.error(err));
```

5. **Listar los títulos de las películas que no se han alquilado nunca**
Sólo me da el campo "title"
```sql
SELECT f.film_id, f.title
FROM film f
JOIN inventory i ON f.film_id = i.film_id
LEFT JOIN rental r ON i.inventory_id = r.inventory_id
WHERE r.rental_id IS NULL
GROUP BY f.film_id, f.title;
```
📘 **Explicación**:   
- Se hace un `LEFT JOIN` para detectar las películas sin ningún alquiler.    
- Si `r.rental_id` es `NULL`, significa que esa copia nunca se alquiló.

Devuelva todos los campos de la tabla + los joins.
```sql
SELECT *
FROM film f
JOIN inventory i ON f.film_id = i.film_id
LEFT JOIN rental r ON i.inventory_id = r.inventory_id
WHERE r.rental_id IS NULL
GROUP BY f.film_id, f.title;
```

# Explicación código Express
## 🧩 **Código línea por línea**
```ts
// Ruta de prueba
app.get('/api/films', async (_req, res) => {
```
*   `app.get(...)` define una **ruta HTTP GET**.
*   La URL `/api/films` es el **endpoint** que se puede visitar desde el navegador o mediante JavaScript para pedir datos.
*   Esta función se ejecuta cuando alguien accede a esa URL.
*   `_req` es el objeto de **petición** (request), que aquí no se usa, por eso lleva un guión bajo (solo se usa `res`).
*   `res` es el objeto de **respuesta** (response), que sirve para enviar algo de vuelta al cliente (como JSON, HTML, etc.).
* * *
```ts
  try {
    const [rows] = await db.query('SELECT * FROM film');
```
*   Intenta ejecutar una consulta SQL (`SELECT * FROM film`) en la base de datos, usando `db.query`.
*   `await` significa que la ejecución **espera** a que termine la consulta antes de continuar.
*   `rows` contiene las filas (películas) obtenidas de la tabla `film`.
* * *
```ts

    res.json(rows);

```
*   Si todo va bien, se envían los datos al cliente en formato JSON, es decir, una lista de películas.
* * *
```ts
  } catch (error) {
    res.status(500).json({ message: 'Error al consultar la base de datos', error });
  }
});
```
*   Si hay un error en la consulta, se captura con `catch`.
*   Se responde con un **estado 500 (error interno del servidor)** y un mensaje de error.
* * *
```ts
// Usar rutas
app.use('/api/films', filmRoutes);
```
*   `app.use` registra un **middleware o grupo de rutas**.
*   Aquí, si `filmRoutes` contiene más rutas como `/123`, se acceden mediante `/api/films/123`.
*   Esto complementa la ruta anterior, que era de prueba. Este `filmRoutes` seguramente viene de otro archivo donde defines rutas más organizadamente.
* * *
```ts
// Middleware para archivos estáticos
app.use(express.static(path.join(__dirname, '../../frontend/public')));  // CSS, imágenes, etc.
```
*   Esto sirve para **servir archivos estáticos** (que no cambian dinámicamente), como CSS, imágenes, fuentes, etc.
*   Usa `path.join(...)` para construir la ruta absoluta a la carpeta `frontend/public`.
* * *
```ts
app.use('/dist', express.static(path.join(__dirname, '../../frontend/dist')));  // JS compilado
```
*   Igual que el anterior, pero esta vez sirve los archivos del directorio `dist` bajo la ruta `/dist`.
*   Es útil si usas TypeScript y compilas a JavaScript: los archivos transpilados suelen quedar en `dist`.
* * *
```ts
// Ruta para el frontend (index.html)
app.get('/', (_req, res) => {
  res.sendFile(path.join(__dirname, '../../frontend/public/index.html'));
});
```
*   Define la **ruta principal del sitio web** (la página inicial `/`).
*   Cuando alguien entra a la web (ej. `http://localhost:3000/`), se le sirve el archivo HTML principal.
*   `sendFile(...)` envía directamente el archivo `index.html` desde la carpeta pública.
* * *
### 🧠 Resumen simplificado
*   `app.get('/api/films')`: responde con todas las películas en JSON.
*   `app.use('/api/films', filmRoutes)`: incluye rutas adicionales definidas en otro archivo.
*   `express.static(...)`: sirve archivos como CSS o imágenes al navegador.
*   `app.get('/')`: muestra la página principal (`index.html`) del frontend.
