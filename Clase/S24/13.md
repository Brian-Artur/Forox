3. sudo unzip wordpress-6.8.1.zip sedescomprime
4. Necesitamos una base de datos. Podemos ir al phpMyAdmin
	1. Nueva 
	2. Le damos un nombre
	3. Crear
	4. Vamos a "bases de datos" y nos fijamos qué cotejamiento tiene la base de datos.
5. `sudo mv wordpress/ pagina_web/` cambiar el nombre de la carpeta
6. `sudo chown -R www-data:www-data paginas_web`
7. Ir al navegador
	1. localhost/paginas_web/
	2. Let's go
	3. Configuramos el perfil
		1. username: root
		2. base de datos: mariadb
		3. cambiar el prefijo que da por defecto
		4. confirmamos
	4. Ahora configuramos el sitio web
