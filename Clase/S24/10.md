# Manipulación del DOM
1. Obtenemos el elemento padre.
2. Creamos el elemento que necesitamos insertar.
	- Siempre tenemos que asignarle ese elemento creado a una variable. Porque sino, no podremos utilizarlo.
3. Usamos el append() para introducir el elemento creado, al padre.
4. Añadir clase al nuevo elemento con .classList.add() .

# Crear proyecto
1. Dibujar el esquema visual del HTML (frontend).
2. Transformarlo a la estructura de etiquetas de los elementos.
3. Crear la lógica de negocio, para aplicar con nuestros propios datos simulados de forma local.
4. Cuando ya vaya la lógica con los valores locales, nos metemos con la implementación de la API. 
	1. Guardamos los datos de la respuesta de la API en una nueva variable. Queremos tener esta información de forma aislada. Y no acoplar el componente.
	2. Ya con esos datos en una variable, es cuando se los pasamos a nuestras variables locales.
	3. Después vamos a encargarnos de manejar los "errores" de la API. Qué pasa cuando no nos devuelve nada?
