# Polimorfismo
El polimorfismo es la capacidad de un objeto de tomar diferentes formas. Un mismo elemento puede servir para varios roles diferentes.

## Sobrecarga vs sobrescritura
En python no hay sobrecarga de métodos, como sí lo hay en Java. Entonces, si redefinimos un método, este va a tener la cualidades de esta última modificación; ya que se remplaza en el flujo de ejecución.
