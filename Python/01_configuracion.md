# Instalación de Python
En el [sitio web](https://www.python.org/) oficial de Python podremos descargar el ejecutable para instalar Python en nuestro ordenador.

Para comprobar la versión que tenemos actualmente, escribimos en la terminal el siguiente comando: 
```bash
py --version
```

# Extensiones
### 1. **Python (Microsoft)**
- **Función principal**: Soporte básico para Python en VSCode.

- **Beneficios clave**: 
    - IntelliSense (autocompletado inteligente)    
    - Navegación entre archivos (Go to Definition)    
    - Soporte para entornos virtuales  
    - Depuración integrada (similar a la depuración en Node.js)    
- **Para ti como JS/TS dev**: Te dará las mismas funcionalidades básicas que ya usas con JavaScript en VSCode.

### 2. **Pylance**
- **Función principal**: Type checking y análisis estático (como TypeScript para Python).  
- **Beneficios clave**:
    - Comprobación de tipos usando type hints (similar a TS)
    - Autocompletado más inteligente
    - Detección de errores sin ejecutar el código
- **Para ti**: Como vienes de TypeScript, te sentirás como en casa con el type checking.
### 3. **Python Indent**
- **Función principal**: Manejo automático de indentación.
- **Beneficios clave**:
    - Corrige automáticamente la indentación al mover bloques de código
    - Previene errores comunes de indentación (el equivalente a los errores de llaves en JS)
 - **Para ti**: Te ayudará a acostumbrarte a que la indentación es sintaxis en Python (no solo estilo como en JS).
