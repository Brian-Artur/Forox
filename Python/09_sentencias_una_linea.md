# Varias sentencias en una línea
Es posible escribir varias sentencias en una sola línea, separándolas por punto y coma; como lo hace JavaScript con la coma.
```python
x = 5; y = 10; print(x + y)  # Output: 15
```
- **No es recomendable** usarlo habitualmente (va contra el estilo "pythonico" PEP 8). 
- **No genera error**, pero puede confundir a otros desarrolladores Python.
- **No afecta el rendimiento** (el intérprete lo ignora).
