# Non local
Utilizamos la palabra reservada `nonlocal` para decirle a python que esa variable que vamos a mencionar, en este ámbito local, no es una nueva variable. Sino que estamos haciendo referencia a una variable global ya existente.

De esta forma ya no nos generará esa nueva variable. Y podremos modificar el nombre de la variable anterior.
