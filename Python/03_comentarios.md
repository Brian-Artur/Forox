# Comentarios
Como en JS, existen dos tipos de comentarios. Los monolínea que se escriben con `#` y los multilínea, que se escriben con `"""` de apertura y de cierre.

Hay que tener en cuenta que los comentarios multilínea se usan principalmente para generar la documentacion, como un JSDocs. Es por eso, que si queremos usar más de una línea para comentar nuestro código, lo mejor es que encadenemos varios comentarios monolínea.
