# Web Scraping
**Web Scraping** significa **extraer datos de páginas web automáticamente**, usando un programa escrito en Python (u otro lenguaje).

En vez de copiar y pegar datos manualmente, tu script de Python **lee el HTML** de una web, **busca lo que te interesa** (por ejemplo, títulos, precios, artículos, etc.) y **lo guarda** (por ejemplo, en un archivo CSV, una base de datos, o simplemente lo muestra en pantalla).
