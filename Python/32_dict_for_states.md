# Diccionarios para estados
![[Pasted image 20250615105948.png|300]]
Vemos que estamos empleando un diccionario {clave : valor} para albergar un contador. Luego, simplemente usamos la notación de corchete para modificar el valor de ese contador en un función interna.

Con un para de `return` ya somo capaces de obtener el valor actualizado de dicho contador.
